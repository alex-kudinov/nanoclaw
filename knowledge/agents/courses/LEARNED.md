# Courses Minion — Learned

## Pipeline Lessons (2026-04-07)

### Model: Use Opus, Not Sonnet
- Sonnet hallucinates attribution (e.g., claimed "ICF recognizes five group typologies" when Kalina never said that)
- Sonnet invents terminology the instructor didn't use ("typologies" instead of "types of groups")
- Sonnet adds counts not stated ("five types" when nobody counted)
- **Both process_one.py AND enrich_session.py now default to Opus**

### Recap Grounding Rules (in STUDENT_RECAP_PROMPT)
- Every claim must trace to something explicitly said in the transcript
- Use the instructor's own language — do not upgrade or embellish
- Do NOT attribute ideas to organizations (ICF, etc.) unless the speaker explicitly did
- Do NOT invent terminology or add counts not stated
- If source/authority wasn't stated, present as "what was covered in class"

### Email Rendering: Format Tolerance
- Recap markdown format varies between models (numbered vs bulleted, `**Title** —` vs `**Title.**` vs `**Title**:`)
- All regexes handle colon `:`, em dash `—`, en dash `–`, hyphen `-`, and period `.` separators:
  - Key Concepts: `- **Title** — Desc`, `**Title.** Desc`, `**Title**: Desc` (with/without bullet)
  - Instructor Highlights: same flexible pattern including colon separator
  - Reflection Questions: `1. question` and `- question`
- No manual recap format fixing needed — distribute_session.py handles all variants (fixed 2026-04-14)

### Free Course Validation (added 2026-04-14)
- distribute_session.py validates free-course.json entries against course.json before rendering
- Invalid lesson_id entries are auto-rejected (logged to stderr)
- Titles are overwritten with canonical versions from course.json — prevents hallucinated titles
- Static fallback `valid-lesson-ids.json` ships with enricher scripts (available in container)
- If ALL entries are rejected, free course section renders empty — report this, do NOT fabricate replacements
- Root cause of prior hallucinations: enrich_session.py had wrong path to course.json (fixed 2026-04-14)

### Email Validation (10 checks, gates all sends)
1. No unreplaced `{{PLACEHOLDER}}` tags
2. All 4 required sections have content (Key Concepts, Instructor Highlights, Go Deeper, Reflection Questions)
3. No raw markdown in rendered HTML (`**`, `*`, `- `, `#`)
4. Key Concepts count matches recap
5. Instructor Highlights count matches recap
6. At least 2 reflection questions
7. Article URLs have UTM params
8. Matched `<strong>`/`<em>` tags
9. Session title present and >10 chars
10. Free course units rendered if section header present

- Until fixed: only one session per day can be enriched; second run destroys the first
